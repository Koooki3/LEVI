# VLASH 推理模式

工作站提供“普通推理 / RTC / VLASH”三个互斥模式，选择同步到策略部署、命令生成、服务匹配与评测。旧请求只有 RTC 布尔字段时保持原含义；模式字段冲突会被拒绝。

本功能将 VLASH 的未来状态异步分块机制适配到现有 openpi，是实验性实现，不表示现有权重已经完成官方延时增强训练。只允许已核对的带状态条件 FR3 绝对位姿/夹爪配置。VLASH 专属的提前推理步数默认 2，必须大于零且小于动作块长度。

按[适配器说明](../integrations/vlash/README.md)安装隔离入口。两个现有客户端的显式调度扩展复用原安全检查、人工放行与录制流程，每个 episode 单独创建和关闭调度器，日志使用独立 `vlash` 字段。普通服务器不能被默认为支持 VLASH，运行中的 episode 不会被切换到另一模式。

本轮不包含动作量化加速、自动训练、RTC 与 VLASH 叠加或自主真机运动。实际性能、跟踪与停止效果仍需现场验收。

本版支持工作站第 2–4 步的策略部署与人工评测。第 5 步 AERI 暂不支持 VLASH，封闭模式校验会拒绝该模式，不会静默回退为普通推理。
