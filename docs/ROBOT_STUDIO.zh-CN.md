# FR3 机械臂工作台

[English](ROBOT_STUDIO.md)

从顶栏的“FR3 三维预览”链接、marvel_workstation 页标题下的卡片或命令面板（`Ctrl+K` / `⌘K`）打开 **FR3 交互预览**，或直接访问 `/robot-studio`；页面里有回到 marvel_workstation 的链接。这是支持可选只读实测映射的设计工作区：加载固定版本的本地 FR3 与工具模型，拖动本地法兰目标的位置和朝向，导出预览点。状态视图只读取已有的被动快照，不发送机器人指令，也不采集实机示范。

## 使用预览

1. 等待模型加载，选择“平移”或“旋转”，拖动箭头或圆环。拖动背景转动视角，滚轮缩放。“查看”模式隐藏操作手柄。
2. 手柄可选择基坐标系或法兰坐标系。位置字段始终使用基坐标系、单位毫米；朝向字段采用 XYZ 欧拉角、单位度。求解器内部使用米和 `xyzw` 四元数。
3. 编辑数值后按“应用目标”，可完全通过键盘操作。展开“关节与限位”可分别调整关节角。拖拽时按 Esc 恢复拖拽前的姿态；窗口失焦也取消拖拽。“恢复初始预览”只恢复示意模型姿态。
4. 求解失败时，目标标记仍可见，机械臂模型保留最后的有效姿态；页面显示求解残差，禁止保存该目标。靠近限位时，数值求解器也可能无法求出实际上可达的目标，因此失败不等于不可达证明。
5. “添加姿态”将有效配置保存在当前页面内存，最多 100 个。“撤销末项”删除最后一点；“导出 JSON”下载草稿。刷新或离开页面会丢失未导出的点。点序列不包含时间戳、速度或插值轨迹。

页面沿用 LEVI 中英双语和浅深主题；三维区域保持深色，参数区跟随主题。数值字段提供拖拽以外的输入方式。WebGL 或模型加载失败时显示重试入口，不回退显示其他机器人。

## 模型与计算

渲染和求解使用同一份官方 FR3 名义运动学链，从 `fr3_link0` 到法兰 `fr3_link8`。机械臂链止于法兰；另有 Robotiq 2F-85 名义模型，不假定实际安装或 TCP 已标定。初始关节角仅用于预览，不是实测状态或回零指令。[SOURCE.md](../public/robots/fr3/SOURCE.md) 和 [SOURCE.json](../public/robots/fr3/SOURCE.json) 记录固定上游版本、源文件与输出哈希、转换方法及 Apache-2.0 许可。

正运动学与 URDF 链做交叉检查。逆运动学使用带限位、由当前姿态初始化的阻尼最小二乘求解；失败时不应用部分解。场景按需渲染，模型资源从本地加载，不依赖运行时外部 CDN 或环境贴图。

关节限位和 IK 解不能证明无碰撞、动力学可行或实机安全。当前未实现自碰撞与场景碰撞检查。

## 草稿导出与后续数采

含工具的 `levi_robot_preview_v2`（不含工具的旧 helper 为 v1）文件注明机械臂、基座/末端坐标系和单位，并明确包含 `hardware_execution: false`、`collision_checked: false`、`calibrated_tool: false`。每个点保存七个关节角和由其重新计算的法兰位姿。它是设计草稿，不是数据集片段或可以直接执行的机器人轨迹。本次改动没有提供接收该文件的真机执行端点。

后续数采应通过单独审查的后端适配器接入：

- 绑定经确认的机器人配置、实测初始关节角、相机源和工具标定；缺少标定时保留缺失，不猜测常量，也不把法兰冒充夹爪 TCP。
- 在网页、SpaceMouse、策略之间管理唯一控制权。校验指令时效、坐标系和限位；释放使能、窗口失焦或连接过期时撤销目标。前端提示不能证明机器人已经停止。
- 将受限目标交给既有控制器，后端检查实际反馈、碰撞约束和故障。不能让过期的浏览器目标无限续发。
- 同步保存相机观测、实测状态、经过约束后实际下发的动作、夹爪语义、采集时间戳和控制来源；预览目标、下发指令与实测状态分别记录。
- 延续真机运动与数采的人工授权，以及项目服务和资源所有权协议。

页面可选择读取既有被动快照，仍没有机器人 IP 配置、运动请求或“开始数采”操作。离线测试与软件审查不代替真机验收。

## Robotiq 2F-85 预览

页面已加入本机 ROS 描述中的 2F-85 本地模型，保留驱动关节、联动关节和 URDF 几何。滑块与“按住打开/关闭”只改变浏览器模型；松开、失焦或页面隐藏时停止动画。开度是连续值，1 为全开、0 为闭合；毫米宽度按连杆几何的非线性关系计算，不把关节转角线性当作物理宽度。许可、来源与哈希见 [Robotiq SOURCE.md](../public/robots/robotiq-2f85/SOURCE.md)。

安装变换与 TCP 都是**未核实的草稿**，初始均未设置。未配置安装变换时，夹爪仅在法兰原点示意。安装变换表示“法兰 → 夹爪底座”，TCP 表示“夹爪底座 → 拟定 TCP”。输入用毫米与 XYZ 欧拉角（度），保存用米和 xyzw 四元数。这些字段不修改 Desk、工具标定、负载、现有法兰逆解目标或控制器配置。只有两项变换都有值时，才显示草稿 TCP 坐标轴。

## 空间边界与速度草稿

边界使用机器人基座坐标系 `fr3_link0`，输入 X/Y/Z 的最小值、最大值六个坐标。应用后显示琥珀色三维框。拖拽或关节调整的法兰目标在框外时，预览保留上次有效姿态并禁止保存该目标。未设边界明确表示“未配置”，不表示允许无限制运动。这里检查的是法兰**目标点**，不检查机器人连杆、工具扫掠体、运动中间路径或障碍物。

配置编辑器包含可选的平移/旋转速度、位置/角度步长、指令超时和夹爪开度变化率。空白保持 null，不猜测现场默认值。**这些是导出草稿，不是真机当前生效约束。** 鼠标拖得快不会发送机器人指令。后续执行监管器必须在后端按单调控制时间逐条限制平移和旋转速度、单步增量及必要的加速度，并检查实际当前位置、目标和工具扫掠边界、反馈新鲜度、序号、超时与持续使能。网页字段不能覆盖既有控制器限值、client-enable、就绪条件或控制权规则。

## 只读实测状态接入

页面默认开启只读读取并进入“跟随实际”。真实产品在本机控制文件明确设置 `[manual] enabled = true` 后，从站点固定的 `server.robot_server_url` 读取 `GET /manual/v1/state`；只读显示不会启动手动会话、控制器或发出运动。Robot Server 需安装并由操作者重启以加载[已审查的协议适配器](../integrations/fr3_manual/README.md)。旧版、缺失或不可达的来源明确显示未知，不用默认姿态冒充实测。

未启用真实来源时仍支持现有 `LEVI_WORKSPACE/robot-studio/telemetry.json` 文件。真实读取独立检查机械臂与夹爪的源单调时钟和新鲜度：夹爪未知时隐藏夹爪，但仍可显示有效的机械臂关节。Robot Server 的 Desk EE 单独标注，不当作模型法兰 `fr3_link8`。

读取器只接受固定路径下大小受限的普通文件，拒绝路径组件中的符号链接，并校验有限数值、单位、结构、时间戳和四元数。状态包括新鲜、过期、缺失、无效和不可用。只有不超过一秒的样本返回实测值。未来时间偏差超过 50 ms 则无效；容许范围内的轻微时差返回非负数据年龄。即使轮询停止，网页也会按单调经过时间让显示过期。接口沿用普通 UI 鉴权，没有写入、启动或使能端点；读取成功不代表运动就绪或获得许可。

### 初始对齐与跟随/编辑模式

选择“读取快照”后，默认进入**跟随真机**模式。首帧新鲜反馈到达前，机械臂与目标隐藏，位姿字段留空；示意初始姿态不会被当成实测姿态。首帧直接设置模型的七个实测关节角、由 FK 计算的法兰位姿，以及可用的连续夹爪开合度。后续快照持续更新白色只读模型，不通过 IK 改写实测关节。实测法兰在草稿安全框外时仍如实显示并提示，但禁止从该姿态进入目标编辑。安装与 TCP 仍使用未验证草稿，因此关节对齐不代表工具标定已完成。

“从实测姿态编辑目标”会在点击时重新检查反馈新鲜度，再以该帧反馈建立本地目标。后续反馈只更新蓝色实测层，不覆盖白色编辑目标或夹爪草稿，拖拽期间也一样。“跟随真机”恢复实测显示；切换时取消排队的本地拖拽。跟随期间修改安全框不会对实测关节重新求解。反馈缺失或过期时，保留最后跟随姿态并明确提示失联或过期，不恢复示意初始关节。停止读取后保留当前本地姿态；重新开启读取时等待新的有效反馈。

实测夹爪转角与物理开口宽度保留各自单位。反馈缺失或超出名义模型行程时，跟随模式隐藏夹爪模型，不假定开合度；如有原始反馈仍显示原值。编辑模式中，未知夹爪反馈不替换当前本地开合草稿。服务报告的 EE 坐标系名称原样展示，不推定它就是法兰或 Robotiq TCP。

页面在上次请求结束后等待 500 ms 发起下一次快照请求，以源数据年龄加请求/经过时间判断过期，并在 1.2 秒后中止未完成请求。这是周期性只读显示，不是伺服控制循环。已接入经审核的 Robot Server v1 只读来源，需操作者重启对应服务后才能提供实测数据。

后续单独审查的只读生产者须输出以下闭合结构；示例数值是合成数据，不是本机标定或真实反馈：

```json
{
  "schema": "levi.robot_studio.telemetry.v1",
  "robot": "fr3",
  "source_id": "read-only-producer",
  "sequence": 1,
  "sampled_at_epoch": 1800000000.0,
  "joints_rad": [0.0, -0.785398, 0.0, -2.356194, 0.0, 1.570796, 0.785398],
  "gripper": {"knuckle_angle_rad": 0.4},
  "reported_ee": null
}
```

所有键都必须存在，gripper/reported_ee 可以为 null。夹爪字段只能二选一：`knuckle_angle_rad` 或 `opening_width_m`。上报末端对象包含 `position_m`、`quaternion_xyzw`、`frame_id` 和 `end_frame`。时间戳应来自实际采样时刻，不能用写文件时间冒充。现有健康摘要没有这组实测关节/夹爪字段，不能代用；合成测试文件也不能标成真机反馈。

## 扩展草稿导出

含工具的导出使用 `levi_robot_preview_v2`，每点保存当时的连续开度和安装/TCP 草稿。执行配置草稿在字段名中标明单位，空间框注明基座坐标、法兰目标及 `checks_tool_sweep: false`。旧预览点按当前框重新标注 true/false/null，不会被悄悄变成已批准指令。`hardware_execution`、`calibrated_tool`、`collision_checked` 和 `execution_draft.motion_enabled` 始终为 false。不带工具/配置的旧版法兰草稿 helper 仍保留。

工具标定和真实数采仍独立于本次显示及手动会话。


## 真实手动平移与夹爪控制

真实适配器由 `[manual] enabled = true` 明确启用。默认测试主机仍关闭，模拟工厂仅供离线测试。页面需一次性确认、输入 `start real translation session` 并勾选操作者核对项。读取反馈、浏览器姿态或预览规划哈希都不授予运动权限。

会话从新鲜实测反馈建立锚点，复用评测的同一把机械臂锁。拖拽发送基坐标中的相对平移，固定原始朝向；模型法兰由实测关节和 FK 显示，后端将同一平移量作用于 Desk EE，避免工具偏置混入位移。旋转仍仅预览。安全框、总位移、步长、速度、反馈/锚点时效、心跳和目标时效均需明确填写，不推断现场默认值。停止阈值另需填写 `settle_window_s`、`settle_position_m`、`settle_angle_rad`、`gripper_settle_rad`。

真实夹爪有独立的按住控制：每次只发送一个有限 `opening_ratio` 目标（0 闭、1 开），随后仅续心跳；本地预览滑块不会驱动硬件。松开、失焦、页面隐藏、取消或心跳丢失会关闭发送并取消目标，不保留反向排队命令。目标自身也有独立有限时效。

v1 服务独立检查身份、序号、时效、边界并排除旧接口并发写。关闭会话时发送实测姿态保持，并取消对应夹爪动作，包括迟到接受的动作。HTTP 或取消确认不是物理停止证明：必须取得停止后持续新鲜且稳定的机械臂/夹爪反馈及动作终态，才释放占用。停止或交付未知时保留占用；页面不能自行提交停止证据。

启动前能力读取失败不会占住锁；启动可能已送达之后的失败保留会话。页面按自己的 `start_request_id` 有限恢复，只用于停止/结束，不自动重新启用。真实与模拟停止证据分开；远端已成功结束后可复用回执完成本地审计，不重复发送结束请求。

安装补丁不会启动 Robot Server。既有启动流程可能激活阻抗，由操作者重启并完成真机验收。离线测试不证明物理停止距离、碰撞余量、工具标定或安全运行参数；重启后不自动恢复运动。

## 参数能力与限值草稿

参数面板区分本地预览草稿、等待逐项接受与读回的笛卡尔阻抗更新、夹爪启动配置，以及尚无在线接口的关节力矩/加速度/外力停止阈值。清单描述已审查的软件能力，不探测当前控制器；控制器实际值保持“尚未接入”。本次没有增加参数写接口；手动运动传输不实现关节力矩、加速度、阻抗或力阈值的在线写入。

限值草稿初始全部留空。关节力矩和加速度分别要求完整填写七个关节；笛卡尔加速度和外力停止阈值是单值草稿。整组可留空，部分填写或非有限正数会阻止导出。不推断硬件上限或现场默认值。字段明确表示限值/停止阈值，不表示力矩或接触力控制目标；服务端的笛卡尔力矩观测不能冒充七关节力矩。

“导出草稿”下载 `levi.robot_studio.parameter_proposal.v1`，字段名携带单位，未知组为 null，`hardware_execution`、`hardware_values_read`、`approved_limits` 均为 false，每项能力的 `can_apply` 为 false。文件与姿态预览独立，不改变手动会话配置、deadman 或停止门禁。控制器更新仍需要核实范围、逐项接受与读回，以及单独审查的适配器；夹爪力/速度变更需要经审核的启动配置流程。

手动会话统计改用四格显示，分别保留目标接受、本地发送、确认、模拟停稳回执的含义；缺失时显示未知。
