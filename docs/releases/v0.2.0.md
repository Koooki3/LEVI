# LEVI v0.2.0 · 机器人数据工坊 / Robot Data Atelier

LEVI 的首个公开版本：默认中文、支持英文的 LeRobot 数据浏览、标注、转换与审核工作台，具备独立 uv 环境和完整内置采集转换流程。

The first public LEVI release brings a Chinese-default, English-capable LeRobot dataset workbench with its own uv environment and a complete built-in capture conversion pipeline.

## Highlights / 主要功能

- Synchronized multi-camera playback, state/action charts, annotations and grounded VQA, statistics, frame galleries, filtering, action insights and compatible URDF playback.
- Local dataset registration, persistent review manifests, version-aware diagnostics and source-safe annotation export.
- Capture preparation, image/video processing, FPS selection, frozen/static checks, configurable filtering, LeRobot v2.1 conversion, timestamp/task repairs and full-decode validation.
- Structured conversion plans and logs, source-change detection, interrupted-job recovery and explicit cache cleanup.
- Original graphite/parchment/lime interface, bilingual guides and the two strawberry demonstration datasets.

包含多相机与曲线同步、语言和视觉标注、统计与动作洞察、首末帧审核、三维回放、本地诊断，以及采集到 LeRobot 的完整内置转换流程。转换和导出写入新目录，保留输入数据。

## Install / 安装

Follow [README.md](https://github.com/Koooki3/LEVI/blob/v0.2.0/README.md) or [README.en.md](https://github.com/Koooki3/LEVI/blob/v0.2.0/README.en.md). Install uv and FFmpeg, then clone the repository, select `v0.2.0`, and run the documented setup/build/serve commands.

## Validation and limits / 验证与范围

- 159 frontend tests and 19 backend/conversion tests passed locally, together with type, lint, format and production-build checks.
- Real-browser checks covered the public demo, annotations, bilingual UI and built-in conversion playback. A separate source checkout and data workspace with spaces passed installation, tests and build.
- Validated on Linux x86_64. Docker runtime, macOS/ARM and WSL2 execution, private Hub login and Hub upload were not exercised in the release environment.
- Video datasets v2.0/v2.1/v3.0/v3.1 can be browsed; built-in capture conversion writes v2.1. Embedded Parquet images and a training-framework loading guarantee are outside the validated scope.

具体证据及限制见 [VALIDATION.md](https://github.com/Koooki3/LEVI/blob/v0.2.0/docs/VALIDATION.md)。这是源码发行，不包含数据集、运行环境、私有配置或预构建容器。
