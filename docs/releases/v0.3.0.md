# LEVI v0.3.0 · 数据集索引与审核加固 / Dataset Indexing and Review Hardening

LEVI v0.3.0 集中修复 LeRobot 数据集版本识别、任务数量统计、任务筛选和跨版本数据读取问题，并加强异常数据、认证缓存和审核工作流的安全边界。

LEVI v0.3.0 focuses on reliable LeRobot version detection, dataset task counting and filtering, cross-version data loading, malformed-metadata handling, authenticated cache isolation and review-workflow hardening.

## Highlights / 主要更新

- 统一支持并规范化 LeRobot v2.0、v2.1、v3.0 和 v3.1 的版本识别；支持旧数据中常见的无 v 前缀或三段版本写法，并一致拒绝不支持版本。
- 按任务索引而不是 Parquet/JSONL 物理行顺序构建数据集级任务表，合并 episode 元数据和帧级 task_index 映射；侧边栏筛选、任务计数和 Action Insights 任务范围现在使用实际数据。
- 支持 v2 JSONL 与 v3 分片 episode 元数据的完整统计，清理重复、越界、非法索引及非有限数值，避免 FPS、时长、图表和时间戳计算产生错误结果。
- 加固后端 episode 路径解析、帧时间戳吸附、语言 atom 校验与导出；原始数据集保持只读，非法元数据会给出明确错误。
- 浏览器 Parquet、数据集信息、统计和任务索引缓存现在有容量上限、LRU 更新、请求复用和 Hugging Face 认证变更失效机制，避免跨账号复用私有数据。
- 修复任务筛选后的分页、空结果导航、键盘切换、认证后刷新、Doctor 标签和 v3.1 语言指令提取等界面问题。
