# LEVI v0.3.0 · Dataset indexing and review hardening

LEVI v0.3.0 focuses on reliable LeRobot version detection, dataset task counting and filtering, cross-version data loading, malformed-metadata handling, authenticated cache isolation and review-workflow hardening.

This maintenance follow-up also makes English the default UI and repository landing language, keeps a professional Chinese translation available from the language switch, hardens standalone-browser behavior, and centers/drags annotation label popups.

## Highlights

- Canonicalized LeRobot v2.0, v2.1, v3.0 and v3.1 version detection, including common unprefixed and three-part metadata aliases, while rejecting unsupported versions consistently.
- Rebuilt dataset task indexing around authoritative task indices, JSONL/Parquet fallbacks, episode metadata and frame-level mappings so task counts, sidebar filtering and Action Insights scopes use actual dataset contents.
- Hardened episode metadata, data-path resolution, timestamp snapping, numeric chart values and diagnostics against malformed, fractional, non-finite, duplicate or stale records.
- Added bounded browser caches, in-flight request sharing and authentication-change invalidation to prevent private-data leakage and unbounded memory growth.
- Fixed task-filter navigation, empty-result handling, statistics counts, v3 episode-length support, language-instruction extraction and review-tab restoration.
- Added a 602-key bilingual catalog with English-first welcome metadata and documentation, safe storage fallbacks for standalone or restricted browser contexts, and localized dynamic status messages.
- Ctrl/Cmd+S now saves the current annotation episode or commits an active draft before the browser's native Save Page action; Ctrl/Cmd+Z/Y undo and redo within the workbench. Annotation popups open centered and can be dragged within the viewport.

## Validation

- Frontend type checks, ESLint, Prettier and production Next.js build passed.
- Bun unit tests: **176 passed, 0 failed** across 10 files; 1,812 expect calls.
- Python / FastAPI tests: **55 passed**; only the existing 2 dependency deprecation warnings remain.
- `uv lock --check`, Ruff, `uv run levi check`, `git diff --check` and the standalone Chromium smoke check passed. The smoke check confirmed `window.parent === window`, three playable demo videos, no horizontal mobile overflow, persisted language selection, centered/draggable popups, all tested Ctrl/Cmd shortcuts canceled before native defaults, and zero page errors.

Detailed evidence and tested limits are recorded in [docs/VALIDATION.md](../VALIDATION.md). This is a source release: it does not include datasets, runtime environments, private configuration, SAM3 weights or prebuilt containers.
